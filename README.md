# Overview

This repository creates a package useful to visualize data from Florence Nightingale's mortality analysis


## Organisation 
Major folders include: 

- 'data' and 'data-raw' folders which contain the key dataset in different formats 

- 'R' folder which contains the analysis scripts namely 'mortality.R', 'show_barplot.R' and 'show_shiny_app.R'

- 'tests' folder which creates synthetic data to test the package
